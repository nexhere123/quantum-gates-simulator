# Quantum Gates Simulator ⚛️

This project is an interactive simulator to visualize quantum gates using Bloch Sphere.

## Features
- Pauli-X, Pauli-Y, Pauli-Z Gates
- Hadamard Gate (Superposition)
- CNOT Gate (Entanglement)
- 3D Bloch Sphere Visualization

## Technologies Used
- Python
- Streamlit
- NumPy
- Plotly
- Matplotlib
- Pandas

## How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Run the app:
   streamlit run proj.py

## Description
This simulator helps students understand quantum mechanics concepts like superposition, phase, and entanglement using interactive visualization.
